- Keep publishing to `fediim-dev/better-auth-kmp` — rejected: the operator asked for kmp-packages, and one org registry lets consumers declare a single repository for FDS and better-auth.
- Publish through CI by pushing tag `v1.0.0` — rejected for now: Actions is in a billing outage (#10), and ci.yml's `GITHUB_TOKEN` is scoped to this repository, so it likely cannot write packages linked to kmp-packages (L3); a local publish from the merge commit is the only path today.
- Publish only jvm/android/js/wasm and skip iOS until #10 — rejected: KMP consumers resolve the root module's variants, and a 1.0.0 missing iOS variants breaks iOS consumers permanently for that version; this host (x86_64 macOS) cross-compiles iosArm64/iosSimulatorArm64 klibs (L4).
