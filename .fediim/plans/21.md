## Alternatives considered
- Add a `sensitive` flag to FDS `CodeBlock` itself — rejected for this issue: FDS is a separate repo heading to 1.0.0 (#20); a change there cannot be consumed until that release, and this repo's fix works with any FDS that keeps `onCopy`.
- Android-only `LocalClipboard` for all platforms with per-platform `ClipEntry` builders — rejected: needs four platform `ClipEntry` constructions (desktop, web, iOS) whose APIs are not needed; the issue's acceptance criterion covers Android only, and plain `setText` already works on the other platforms.
- Clear the clipboard after a timeout — rejected (issue marks it optional): needs a timer that outlives the dialog and could wipe a value the user copied later from another app.
