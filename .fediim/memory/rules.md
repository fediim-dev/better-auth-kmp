# Operator rules

> Always loaded; binds like AGENTS.md. One line per rule, starting DO, DON'T,
> or IMPORTANT (a fact the agent must know). Add via remember-rule or by hand.
DON'T: use `-SNAPSHOT` versions; versions follow SemVer with two-digit pre-releases `-alphaNN`/`-betaNN`/`-rcNN` (e.g. `1.0.0-alpha01`, `1.0.0-rc02`), then the final release; the already-published `1.0.0-rc1` is the one exception.
